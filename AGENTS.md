# AGENTS.md

## Project overview

PollPop is a free, ad-supported online polling site. Visitors create polls without an account, vote once per poll, and see live results. Revenue comes from Google AdSense slots.

Built with TanStack Start (React 19, TanStack Router), Tailwind CSS 4, and Netlify Database (Postgres) via Drizzle ORM. Deployed on Netlify.

## Key directories

```
db/
  schema.ts            # Drizzle schema: polls, poll_options, votes
  index.ts             # Drizzle client (drizzle-orm/netlify-db, no connection string)
netlify/database/migrations/  # Generated by drizzle-kit; applied automatically on deploy
src/
  lib/
    ads.ts             # AdSense env config (VITE_ADSENSE_CLIENT, VITE_ADSENSE_SLOT_*)
    polls.ts           # Client-safe Poll types and CATEGORIES
    format.ts          # pct/compact/timeAgo helpers and bar colours
  server/
    polls.functions.ts # Server functions: listPolls, getPoll, createPoll, castVote
    starter-polls.ts   # Seed polls inserted when the DB is empty
  components/
    AdSlot.tsx         # Renders an AdSense <ins> or a placeholder when unconfigured
    PollCard.tsx       # Poll preview card used in feeds
    SiteHeader.tsx     # Header, logo and footer
  routes/
    __root.tsx         # HTML shell, fonts, AdSense script, header/footer
    index.tsx          # Home: hero + poll feed (?sort=new, ?category=…)
    create.tsx         # Create poll form
    p.$pollId.tsx      # Vote + live results + share
    ads[.]txt.ts       # /ads.txt server route built from VITE_ADSENSE_CLIENT
```

## Non-obvious decisions

- **Vote counting:** `votes` has a unique index on `(poll_id, voter_id)`. `castVote` inserts with `onConflictDoNothing` and only increments the denormalised `poll_options.votes` and `polls.total_votes` counters when the insert succeeds.
- **Voter identity:** an anonymous, httpOnly `pv_voter` cookie set on first vote. There is no IP-based dedupe, so shared networks such as schools and offices can still vote.
- **Views:** `getPoll` increments `views` unless called with `countView: false`. The poll page uses that flag for its 8-second live results refresh.
- **Seeding:** `listPolls` calls `ensureStarterPolls()`, which inserts fixed-id polls only when the table is empty.
- **Client/server split:** keep types and constants that the client needs in `src/lib/polls.ts`. Don't import from `db/` in client code.
- **Ads:** all ad config comes from `VITE_*` env vars at build time. `AdSlot` must keep its "Advertisement" label.

## Conventions

- Tailwind utilities plus a few shared classes in `styles.css` (`.card`, `.btn`, `.input`). Colour tokens: paper, ink, tomato, sun, mint, sky, lilac. Fonts: Bricolage Grotesque (display) and Inter Tight (body).
- Server functions use `.inputValidator(...)` (not `.validator`).
- Schema changes: edit `db/schema.ts`, then `npx drizzle-kit generate --name <verb_change>`. Never edit applied migrations, and never run migrate or push.
- Import alias `@/` maps to `src/`.
